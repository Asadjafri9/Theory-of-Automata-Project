# 🎓 Theory of Automata Project: String Reverser & Calendar DFA

This repository contains our final project for the Theory of Automata course. It includes both a **web-based string reverser** application and a **paper-based DFA model** inspired by calendar transitions.

---

## 🧠 Project Overview

### 🔁 String Reverser Web App
A frontend mini-project built with **HTML**, **CSS**, and **JavaScript** that:
- Takes a user-input string.
- Reverses it using basic JavaScript logic.
- Represents fundamental string operations in the context of automata and formal languages.

### 📆 Calendar DFA (Paper-Based)
A manually crafted **Deterministic Finite Automaton (DFA)**:
- Models calendar-based transitions (days, weeks, months).
- Shows how automata theory applies to real-life systems.
- Created physically on paper as part of the theory demonstration.
